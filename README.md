# Project Zomboid Mod Inspector

Инструмент для анализа модификаций **Project Zomboid** из Steam Workshop.

Программа сканирует установленные моды, индексирует их содержимое и выявляет потенциальные конфликты, ошибки и проблемы с зависимостями.

## ✨ Возможности

* 🔍 Сканирование Steam Workshop
* 🧩 Индексация установленных модов
* ⚠️ Поиск конфликтов между модами
* 📜 Анализ Lua-конфликтов
* 📦 Анализ конфликтов предметов
* 🔗 Проверка отсутствующих зависимостей
* 📋 Анализ порядка загрузки модов
* 📊 Dashboard со статистикой
* 🔎 Поиск модов по названию
* 🟢 Отображение уровня риска
* 📂 Быстрое открытие папки мода
* 💾 Сохранение пути к Steam Workshop
* 🖥️ Portable-версия для Windows
* 🔄 Поддержка автоматической проверки обновлений

## 🖥️ Интерфейс

### Dashboard

Главная панель показывает общую информацию о найденных проблемах:

* количество модов;
* Lua-конфликты;
* конфликты предметов;
* отсутствующие зависимости;
* прогресс сканирования;
* журнал анализа.

### Mods

Таблица содержит:

| Поле     | Описание                        |
| -------- | ------------------------------- |
| Название | Название мода                   |
| ID       | Внутренний ID мода              |
| Workshop | Steam Workshop ID               |
| Risk     | Уровень риска                   |
| Ошибки   | Количество обнаруженных проблем |

Уровень риска обозначается цветными индикаторами:

* 🟢 `0–29` — низкий риск
* 🟡 `30–59` — средний риск
* 🟠 `60–89` — высокий риск
* 🔴 `90+` — критический риск

### Conflicts

Раздел показывает обнаруженные конфликты и связанные с ними моды.

## 📦 Portable версия

Установка Python и дополнительных библиотек для portable-версии не требуется.

Скачайте архив последнего Release, распакуйте его и запустите:

```text
ProjectZomboidModInspector.exe
```

Программа работает непосредственно из своей папки.

## 🚀 Использование

### 1. Выберите Workshop

Нажмите:

```text
📂 Workshop
```

и укажите папку Steam Workshop с модами Project Zomboid.

Обычно моды находятся примерно здесь:

```text
Steam\steamapps\workshop\content\108600
```

где `108600` — App ID Project Zomboid.

### 2. Запустите сканирование

Нажмите:

```text
▶ Сканировать
```

Программа выполнит:

```text
Сканирование
     ↓
Индексация
     ↓
Анализ
     ↓
Поиск конфликтов
     ↓
Формирование отчёта
```

### 3. Изучите результаты

После завершения анализа доступны:

* Dashboard;
* список модов;
* конфликты;
* статистика;
* журнал анализа.

Для открытия папки мода можно сделать **двойной клик по нему** в таблице.

## 🔨 Сборка

Для разработки создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

Запуск из исходников:

```powershell
python main.py
```

Для создания portable-сборки используется PyInstaller:

```powershell
pyinstaller ProjectZomboidModInspector.spec
```

Готовая сборка появится в:

```text
dist\ProjectZomboidModInspector\
```
