# EZ-Scan

Утилита для буферизации и автоматической отправки QR-кодов в рабочее приложение.

**EZ-Scan** принимает QR-коды со сканера, сохраняет их в очередь и автоматически вводит данные в нужные поля программы, выполняя заданную последовательность действий.

Программа особенно удобна для производственных рабочих мест, операторов, тестовых стендов и любых сценариев, где необходимо быстро обработать большое количество QR-кодов.

# 🖥️ Интерфейс

Главное окно EZ-Scan специально сделано компактным, чтобы программа могла постоянно находиться рядом с рабочим приложением.

Основные элементы интерфейса:

```text
┌─────────────────────────────┐
│                             │
│          12 / 24            │
│       QR BUFFER             │
│                             │
├─────────────────────────────┤
│ ▶ Отправить │ ⏹ Стоп       │
├─────────────────────────────┤
│ ⚙ Настройки │ 👤 Профиль   │
├─────────────────────────────┤
│ ⚡ Авто: ВКЛ │ 🗑 Очистить  │
├─────────────────────────────┤
│       Состояние системы     │
└─────────────────────────────┘
```
Программа показывает:

количество QR-кодов в буфере;
текущий статус;
активный профиль;
состояние автоматической отправки;
текущую отправляемую пачку;
текущий QR-код.
📦 Буфер QR-кодов

EZ-Scan позволяет сначала накопить несколько QR-кодов, а затем обработать их автоматически.

По умолчанию:

Размер буфера: 24
Размер пачки: 12

Например:

Сканирование


QR 1
QR 2
QR 3
...
QR 12


        ↓

        ↓

QR 13
QR 14

Количество QR-кодов в буфере отображается непосредственно в главном окне:

12 / 24
⚡ Автоматическая отправка

При включённом режиме:

⚡ Авто: ВКЛ

EZ-Scan автоматически начинает отправку, когда буфер достигает размера пачки.

Например:

Размер пачки = 12


1
2
3
...
11
12
       ↓
▶ Автоматическая отправка

После завершения первой пачки программа продолжит работу с QR-кодами, которые были отсканированы во время отправки.

▶ Ручная отправка

Автоматическую отправку можно отключить:

⚡ Авто: ВЫКЛ

После этого QR-коды будут только добавляться в буфер.

Для отправки используется:

▶ Отправить

Это удобно, если оператор хочет сначала полностью подготовить очередь, а затем запустить обработку вручную.

⏹ Остановка

Во время отправки доступна кнопка:

⏹ Стоп

Она останавливает текущую отправку.

QR-коды, которые ещё находятся в буфере, не удаляются и могут быть отправлены позже.

🚀 Использование
1. Запустите EZ-Scan

Запустите:

python main.py

После запуска появится главное окно программы.

2. Подключите QR-сканер

Сканер должен определяться системой как устройство ввода.

EZ-Scan автоматически ожидает новые QR-коды.

3. Обучите координаты

Откройте:

⚙ Настройки
    ↓

⚙ Настройки
    ↓

При необходимости увеличьте задержки для медленного рабочего приложения.

🔧 Установка
Требования

Для запуска из исходного кода требуется:

Linux;
Python 3.10+;
xdotool;
доступ к устройству сканера.
Установка зависимостей

Клонируйте репозиторий:

git clone https://github.com/kreshe/EZ-Scan.git

Перейдите в каталог:

cd EZ-Scan

Создайте виртуальное окружение:

python3 -m venv .venv

Активируйте его:

source .venv/bin/activate

Установите Python-зависимости:

pip install -r requirements.txt

Если необходимые системные зависимости отсутствуют, EZ-Scan может определить их при запуске.

▶ Запуск

Запуск программы:

python3 main.py
