# EZ-Scan

Утилита для буферизации и автоматической отправки QR-кодов в рабочее приложение.

**EZ-Scan** принимает QR-коды со сканера, сохраняет их в очередь и автоматически вводит данные в нужные поля программы, выполняя заданную последовательность действий.

Программа особенно удобна для производственных рабочих мест, операторов, тестовых стендов и любых сценариев, где необходимо быстро обработать большое количество QR-кодов.

---

## ✨ Возможности

* 📷 Получение QR-кодов со сканера
* 📦 Буферизация до 24 QR-кодов
* 🔢 Отправка QR-кодов пачками
* ⚡ Автоматическая отправка при заполнении пачки
* ▶ Ручная отправка буфера
* ⏹ Возможность остановить отправку
* 🗑 Очистка буфера
* 🎯 Обучение координат элементов интерфейса
* 🖱 Автоматический клик по обученным координатам
* 📋 Автоматическая вставка QR-кода через буфер обмена
* ↵ Автоматическое нажатие Enter
* 🔘 Настраиваемая последовательность кнопок
* 🕒 Настраиваемые задержки между действиями
* 👤 Система профилей
* 💾 Сохранение настроек
* 🔄 Переключение профилей
* ✏️ Переименование профилей
* 🗑 Удаление профилей
* ⌨ Настраиваемые горячие клавиши
* 📊 Отображение текущего состояния буфера
* 📋 Просмотр очереди QR-кодов
* 📖 Встроенная инструкция
* ⚙️ Гибкая настройка рабочего процесса
* 🐧 Работа в Linux
